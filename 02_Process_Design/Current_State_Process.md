# Current State Process (AS-IS)

## Process Name

Manual Employee Onboarding Process

---

# 1. Overview

Currently employee onboarding is performed manually by HR and IT teams.

The process involves multiple handoffs and repetitive activities.

---

# 2. Current Workflow

## Step 1: Employee Hiring

HR confirms a new employee has joined.

↓

## Step 2: HR Data Preparation

HR creates an onboarding spreadsheet.

Information includes:

- Employee details
- Department
- Role
- Start date

↓

## Step 3: IT Receives Request

IT reviews the employee information.

↓

## Step 4: Data Verification

IT checks:

- Completeness
- Accuracy
- Required access

↓

## Step 5: Account Preparation

IT manually prepares:

- Username
- Email address
- System access

↓

## Step 6: Permission Assignment

IT assigns:

- Security groups
- Application access
- Licenses

↓

## Step 7: Communication

IT sends employee onboarding information.

↓

## Step 8: Reporting

IT updates onboarding tracking records.

---

# 3. Current Challenges

## Manual Errors

Examples:

- Incorrect usernames
- Wrong permissions
- Missing access

---

## Time Consumption

Each employee requires significant IT effort.

---

## Poor Visibility

Limited tracking of:

- Completed onboarding
- Failed requests
- Pending actions

---

## Audit Challenges

Manual records make auditing difficult.
